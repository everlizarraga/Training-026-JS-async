# Async JavaScript - Entrenamiento Completo

Entrenamiento intensivo de JavaScript asíncrono: desde Promises básicas hasta patterns avanzados de producción.

## 📚 Contenido

Este repositorio documenta mi proceso de aprendizaje de async JavaScript durante 3 semanas de práctica intensiva.

### Semana 1: Promises Fundamentals
- Creación y consumo de Promises
- Chaining y error handling
- **Proyecto:** Sistema de Tareas Asíncronas con queue y retry logic

### Semana 2: Async/Await + Event Loop
- Sintaxis async/await
- Event Loop (call stack, microtasks, macrotasks)
- **Proyecto:** Visualizador del Event Loop (herramienta interactiva)

### Semana 3: Fetch API + Patterns Avanzados
- Fetch API (GET/POST/PUT/DELETE)
- Promise combinators (all/race/allSettled/any)
- Debouncing, throttling, cancelación
- **Proyecto Final:** Buscador de Películas con TMDb API

## 🛠️ Tecnologías

- JavaScript (ES6+)
- Fetch API
- The Movie Database (TMDb) API
- HTML/CSS (proyectos)

## 🎯 Proyectos Destacados

**Proyecto Final - Buscador de Películas:**
- Búsqueda con debouncing (300ms)
- Cancelación con AbortController
- Caché de búsquedas
- Infinite scroll
- Loading states + error handling
- Estadísticas de requests

**Visualizador del Event Loop:**
- Simulación paso a paso
- Visualización de call stack, microtasks, macrotasks
- Ejemplos interactivos
